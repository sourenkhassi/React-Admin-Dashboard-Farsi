# React Admin Dashboard Farsi

یک داشبورد مدیریتی مدرن ساخته شده با React و Vite، شامل نوار کناری پاسخگو، نمودارهای تعاملی و پشتیبانی از زبان فارسی.

## ویژگی‌ها

- نوار کناری ناوبری پاسخگو
- نمودارهای تعاملی با استفاده از Recharts
- پشتیبانی از فونت فارسی (Vazir)
- رابط کاربری مدرن با آیکون‌های React Icons

## تکنولوژی‌های استفاده شده

- React 18
- Vite
- React Icons
- Recharts
- ESLint

## نصب

1. کلون کردن مخزن:
   ```
   git clone <repository-url>
   cd react-admin-dashboard-farsi
   ```

2. نصب وابستگی‌ها:
   ```
   npm install
   ```

## اجرای برنامه

برای شروع سرور توسعه:
```
npm run dev
```

برنامه در آدرس `http://localhost:5173` (پورت پیش‌فرض Vite) در دسترس خواهد بود.

## ساخت برای تولید

برای ساخت برنامه برای محیط تولید:
```
npm run build
```

## پیش‌نمایش ساخت تولید

برای پیش‌نمایش ساخت تولید به صورت محلی:
```
npm run preview
```

## بررسی کد (Linting)

برای اجرای ESLint:
```
npm run lint
```
